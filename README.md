# Read the Room — Lee Seoeun

UX/UI portfolio site. Live at https://leeseoeuns.github.io

- `index.html` — lobby: zero-gravity shapes (drag & throw), 6×4 archive drawers
- `room.html?r=01…04` — each project as a vertical, webtoon-like scroll, plus **Docent** (읽어주기) and **Screening** (시청) modes
- `js/data.js` — room titles, colors, page list and docent text (edit text here)
- `assets/works/<room>/<page>.jpg` — portfolio pages exported from Figma
